> quick start

Up and running in 2 minutes

No agents. No config files. No dashboards.

01

Install the SDK

$ npm install @prodscope/sdk-browser
02

Add the Vite plugin

vite.config.ts
import { prodscope } from "@prodscope/sdk-browser/vite"

export default defineConfig({
  plugins: [prodscope({ apiKey: process.env.PRODSCOPE_API_KEY })],
})
03

Init in your app entry

main.tsx
import { init } from "@prodscope/sdk-browser"

init({
  projectId: "my-app",
  apiKey: import.meta.env.VITE_PRODSCOPE_API_KEY,
})

Done. Open VS Code and see production data on every function.

> sdk reference

Full setup

Browser apps, Node.js backends, and Claude Code integration.

@prodscope/sdk-browser $ npm install @prodscope/sdk-browser
1 Add the Vite plugin

Instruments every exported function at build time with file:line metadata.

vite.config.ts
import { defineConfig } from "vite"
import { prodscope } from "@prodscope/sdk-browser/vite"

export default defineConfig({
  plugins: [
    prodscope({
      apiKey: process.env.PRODSCOPE_API_KEY,
    }),
  ],
})
2 Initialize in your entry point

Call init() once — before anything else renders.

main.tsx
import { init } from "@prodscope/sdk-browser"

init({
  projectId: "my-app",
  apiKey: import.meta.env.VITE_PRODSCOPE_API_KEY,
  environment: import.meta.env.MODE,    // "production" | "staging"
  release: import.meta.env.VITE_GIT_SHA, // optional
})

1 Initialize at startup

Must be the first import in your entry file.

index.ts
import { init } from "@prodscope/sdk-node"

init({
  projectId: "my-api",
  apiKey: process.env.PRODSCOPE_API_KEY,
  environment: process.env.NODE_ENV,
  release: process.env.GIT_SHA, // optional
})
2 Express middleware

Tracks every route — method, path, status code, latency.

app.ts
import express from "express"
import { expressMiddleware } from "@prodscope/sdk-node/express"

const app = express()
app.use(expressMiddleware()) // before routes
3 Database middleware

Pick your adapter — or use both.

import { PrismaClient } from "@prisma/client"
import { prismaMiddleware } from "@prodscope/sdk-node/prisma"

const prisma = new PrismaClient()
prisma.$use(prismaMiddleware())
import { Pool } from "pg"
import { pgMiddleware } from "@prodscope/sdk-node/pg"

const pool = new Pool({ connectionString: process.env.DATABASE_URL })
pgMiddleware(pool) // wraps in-place

tracked automatically

express routes & status prisma queries & duration raw sql (sanitized) unhandled exceptions rejected promises slow query detection
