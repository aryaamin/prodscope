Up and running in 2 minutes

Install the SDK, add one config line, and every function in your app is tracked — no manual wrapping.

1

Install the SDK

npm install @prodscope/sdk-browser

For Node/Express apps: npm install @prodscope/sdk-node

2

Add the Vite plugin

import { prodscope } from "@prodscope/sdk-browser/vite";

export default defineConfig({
  plugins: [
    prodscope({ apiKey: process.env.PRODSCOPE_API_KEY }),
  ],
});

The Vite plugin instruments every exported function at build time with file:line metadata.

3

Init in your app entry

import { init } from "@prodscope/sdk-browser";

init({
  projectId: "my-app",
  apiKey: import.meta.env.VITE_PRODSCOPE_API_KEY,
});

Install the VS Code extension and see live production data on every function.

SDK Reference

Everything you need to get production telemetry flowing in minutes.

@prodscope/sdk-browser
$ npm install @prodscope/sdk-browser
1
Add the Vite plugin
Instruments every exported function at build time — no manual wrapping needed.
vite.config.ts
import { defineConfig } from "vite"
import { prodscope } from "@prodscope/sdk-browser/vite"

export default defineConfig({
  plugins: [
    prodscope({ apiKey: process.env.PRODSCOPE_API_KEY }),
  ],
})
2
Initialize in your app entry
Call init() once before anything else renders.
main.tsx
import { init } from "@prodscope/sdk-browser"

init({
  projectId: "my-app",
  apiKey: import.meta.env.VITE_PRODSCOPE_API_KEY,
  environment: import.meta.env.MODE,    // "production" | "staging"
  release: import.meta.env.VITE_GIT_SHA, // optional — for deploy diffs
})

@prodscope/sdk-node
$ npm install @prodscope/sdk-node
1
Initialize at startup
Must be the first import in your entry file to instrument all subsequent modules.
index.ts
import { init } from "@prodscope/sdk-node"

init({
  projectId: "my-api",
  apiKey: process.env.PRODSCOPE_API_KEY,
  environment: process.env.NODE_ENV,
  release: process.env.GIT_SHA,  // optional — for deploy comparison
})
2
Express middleware
Tracks every route — method, path, status code, and latency.
app.ts
import express from "express"
import { expressMiddleware } from "@prodscope/sdk-node/express"

const app = express()
app.use(expressMiddleware()) // add before your routes
3
Database middleware
Pick the adapter for your database — or use both.
import { PrismaClient } from "@prisma/client"
import { prismaMiddleware } from "@prodscope/sdk-node/prisma"

const prisma = new PrismaClient()
prisma.$use(prismaMiddleware())
import { Pool } from "pg"
import { pgMiddleware } from "@prodscope/sdk-node/pg"

const pool = new Pool({ connectionString: process.env.DATABASE_URL })
pgMiddleware(pool) // wraps the pool in-place
